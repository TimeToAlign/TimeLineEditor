Set the inspector’s title line in IBM Plex Mono, bundled with the editor#

Status: accepted · Date: 2026-10-19

Context#

The inspector’s first tab is named by the level the canvas is at (Arranger, Bundle, Group or Timeline), and its panel opens with one title line, “ ”: the level’s word in one style and the name of the workspace or of the edited element in another, set as a console field in a typewriter face. The line should look the same on every platform, so the face is bundled rather than taken from the system. The editor already bundles one face, DejaVu Sans 2.37 from the schema package, for the drawing; it carries no monospaced face, and the text areas and codes of the inspector name the platform’s monospaced stack (ui-monospace, "DejaVu Sans Mono", Menlo, Consolas, monospace).

The requirements:

  1. A typewriter look: monospaced, with slab serifs, readable at 11 to 15 CSS pixels.

  2. One file: the two styles of the line come from size, case, letter spacing and colour, so one upright regular weight serves.

  3. Coverage: Latin-1 and Latin Extended-A complete, since names are mostly European; a character the face lacks (Greek, the accidentals ♭ and ♯) falls back glyph by glyph to the platform’s monospaced face.

  4. Small: a WOFF2 file published upstream, so the bytes are the upstream release’s, unconverted.

  5. A licence that permits bundling in an MIT application with the licence text in the notices file.

  6. No package: a static file vendored beside the editor’s sources; no npm package is installed for it.

Considered options#

Each candidate was taken from its upstream release on 2026-10-19 and measured with fontTools (character map coverage of Latin-1 U+00A0–U+00FF, Latin Extended-A U+0100–U+017F, Greek U+0391–U+03C9, Cyrillic U+0410–U+044F, and U+266D–U+266F).

  • Courier Prime 3.018: the most literal typewriter face (a redrawn Courier), but no tagged release, no upstream WOFF2, no change since 2019, and no Greek or Cyrillic.

  • JetBrains Mono 2.304: good coverage, but a coding face without serifs, and nearly twice Plex Mono’s bytes.

  • The platform’s ui-monospace stack: no bytes, no notice and no maintenance, but not bundled: SF Mono where the browser maps ui-monospace (Safari on Apple systems), elsewhere whatever monospace resolves to (Consolas, DejaVu Sans Mono, Liberation Mono), so the line looks different on every platform, and on none like a typewriter.

  • Write it ourselves: designing and hinting a typeface is a craft of its own, out of all proportion to one line of the inspector.

Decision#

Bundle IBM Plex Mono 2.5.0 Regular: the file fonts/complete/woff2/IBMPlexMono-Regular.woff2 of the release archive ibm-plex-mono.zip of @ibm/plex-mono@2.5.0 (font revision 2.005), copied unchanged to app/packages/editor/fonts/IBMPlexMono-Regular.woff2 (49,248 bytes, SHA-256 ba204497f16b6d334cee9d1e963a831b73e3a56e1d6300a8489d18df7214b350), with the archive’s LICENSE.txt beside it as fonts/LICENSE.txt. The inspector’s stylesheet declares it with @font-face as the family “TiLiE Plex Mono” (font-display: swap), which only the title line names, followed by ui-monospace, monospace for the characters it lacks. The About pane lists it with its licence and copyright line, and the notices file carries its full licence text after DejaVu Sans’s. The build test requires the emitted asset to equal the vendored file byte for byte.

Superseded in part (2026-11-16). The editor bundles a second drawing face from the schema package, Noto Music 2.004, for what DejaVu Sans does not map (TimeToShare’s decision 0012), so it carries three faces; the notices file holds IBM Plex Mono’s licence after Noto Music’s.

Maintenance and dependencies#

No package and no code: one static file and its licence. IBM maintains Plex in IBM/plex (11,713 stars on 2026-10-19), publishing each face as its own release; the static Regular of 2.5.0 is final as it stands, so the file changes only by a decision to take a later release, checked against this record.

What the builds gain: the page build and the embed build each emit the file as one asset, 49,248 bytes, which the browser fetches only when the title line is first shown (a face is loaded on use, so a host page that never opens the inspector never fetches it); the stylesheet gains the minified @font-face rule, 159 bytes in the embed’s tilie.css (measured on the embed build of 2026-10-19) and seven fewer in the page’s stylesheet, which lies beside the asset and so names it without the assets/ prefix. No script bytes. The wheel carries the page build, so it gains the same asset.

Primary sources: IBM/plex, IBM/plex, dejavu-fonts/dejavu-fonts, quoteunquoteapps/CourierPrime, JetBrains/JetBrainsMono, https://openfontlicense.org/open-font-license-official-text/.

Consequences#

The title line looks the same in every browser and in every host page of the embed. Greek letters and the accidentals ♭ and ♯ in a name are drawn by the platform’s monospaced face, so a name holding them mixes two faces. The Reserved Font Name binds only modified versions; the file is shipped unmodified. Exit cost: the two files in fonts/, the @font-face rule, the attribution, the notice and the build test’s lines.

Review date#

2027-04-19, or when a release of IBM Plex Mono adds Greek or the musical accidentals.
