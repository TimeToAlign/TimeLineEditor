Changelog#

Release entries are written by release-please from the Conventional Commits since the previous release.

0.3.0 (2026-10-22)#

⚠ BREAKING CHANGES#

  • address elements by objects and accept free ids unique across a manifest

  • manifests and workspace files must carry the marker “timetoshare”: “0.1.0”; a file with the marker “timeskeleton” is refused as not a TimeToShare manifest.

  • read the revised manifest with abstract conversion maps, measure maps and flow-control elements

  • the workspace file is format version 3, which adds sessions and a session entry kind to the journal and places and bands to every block; version 2 files are refused.

Features#

  • address elements by objects and accept free ids unique across a manifest (d732333)

  • bands as units, drawn per timeline and moved in the timeline editor (1aef4ae)

  • draw a timeline in several groups with one card per group (ec38bc1)

  • edit bundles, groups and timelines in editors on the canvas (2dc066b)

  • edit group and bundle blocks, drawn with cards, frames and ancestor lines (d0393c1)

  • hold one manifest shape per block, with segment delete, unknown length and unknown-key warnings (e54e60a)

  • level tab, workspace name, gap spacing and editor selection fixes (9aa5fe8)

  • mark every box around the selection, thinning outward, and name every inspected element (bbd82f8)

  • read and write TimeToShare 0.1.0 manifests (1b20731)

  • read the revised manifest with abstract conversion maps, measure maps and flow-control elements (8a41908)

  • resize every box alike, undo one change at a time, edit each element’s geometry (03b738f)

  • select the box a press hits, refuse segment Delete, show a disabled Locked checkbox (54e322f)

  • split the inspector into Properties and Manifest tabs, with a minimal view (a8d46a4)

  • stretch every box vertically and keep requested margins in proportion (64f1a95)

  • undo closed editor sessions by runs, move a multi-selection in the bundle editor (4f0c747)

Bug Fixes#

  • mark a group frame that holds the selection, and show Locked as a plain readable checkbox (6c2eea5)

0.2.0 (2026-10-12)#

⚠ BREAKING CHANGES#

  • the 24 earlier commands are replaced by add, set, remove and style; workspace values hold blocks; manifests follow timeskeleton 0.5.0.

  • block records and commands use scale for the drawing scale; zoom, margins, background and nameColumn are no longer accepted.

  • draw manifests per the TimeSkeleton drawing specification

  • separate the workspace, its blocks and their manifests

Features#

  • arrange blocks on a Svelte Flow canvas (0ad0eeb)

  • core: the editable TimeSkeleton document with commands, invariants and a Yjs binding (ac427a7)

  • draw manifests per the TimeSkeleton drawing specification (4801604)

  • edit the workspace through four addressed commands and a journal (f86591f)

  • lay out TimeSkeleton documents and write them as SVG and TikZ (0218776)

  • open, save, import and inspect workspaces in the editor (2011c6a)

  • rename zoom to scale and draw per the revised specification (1a18f0b)

  • separate the workspace, its blocks and their manifests (9723c6c)

Bug Fixes#

  • editor: keep the selection in step with the canvas and make the placement form follow gestures (91dbaed)

[0.1.0] - 2026-10-10#

Added#

  • A pnpm TypeScript workspace with six packages and an enforced dependency ladder.

  • A Svelte 5 browser shell with Arranger, Inspector, and Diagnostics panes and a health readout.

  • A FastAPI local server with token, Host, and Origin protections, /api/health, static app serving, and the tilie command.

  • Python and TypeScript test gates, dependency checks, release version checking, CI, wheel bundling, and PyPI trusted-publishing workflow configuration.

  • Architecture decisions for the selected tools and distribution design.

  • Referrer-Policy: no-referrer on every server response.

Changed#

  • tilie hands the run’s token to the editor in the URL fragment (/#token=…) instead of the query, so it never reaches the server’s access log; the editor removes it from the address bar and the history entry.

  • The tilie-server classifier is Development Status :: 3 - Alpha.

  • The server manifest declares compatible ranges for its runtime and build dependencies (fastapi>=0.141,<1, uvicorn[standard]>=0.53,<1, hatchling>=1.32); uv.lock keeps the exact resolved versions.
