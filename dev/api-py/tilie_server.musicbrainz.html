tilie_server.musicbrainz#

A client of the MusicBrainz web service, within its rules of use.

MusicBrainz asks every client of https://musicbrainz.org/ws/2/ for at most one request per second and a User-Agent naming the application and where to learn about it. This client keeps both for the whole server: one MusicBrainz per application sends its requests one after the other, each at least MusicBrainz.MIN_INTERVAL seconds after the previous one, and answers a URL it has fetched before from its cache without asking again. The User-Agent names the server and its repository, never a person.

The fetch, the clock and the sleep are injected, so the rules can be proved without the network and without waiting.
