The tilie command: start the server and open the editor, or serve it publicly.

The address a public run binds: every interface, so that a proxy or a container’s port mapping reaches it.

tilie_server.cli.port_is_free(port)[source]#

Whether port could be bound on the loopback interface a moment ago.

The port is bound as the server binds it: with SO_REUSEADDR outside Windows, so that the connections of a run just stopped do not hold it. On Windows the option would let a second socket share a port in use.

Parameters:

port (int)

Return type:

bool

tilie_server.cli.settings_for(args, port)[source]#

The settings of the run args asks for, on port.

A public run binds every interface, answers as the given hosts, checks no token, serves no files, bounds request bodies and posted tables, and limits its computations and connections; a local run binds the loopback interface with a new token and serves the files below its root.

tilie_server.cli.main(argv=None)[source]#

Run the tilie command and return its exit status.

A public run prints what it serves; a --check run prints the health document once the checks pass, then stops; a local run prints the editor’s URL, the token in its fragment, and opens a browser unless --no-browser is given.

Returns:

0 on success, 1 if the server did not start or a check failed.
