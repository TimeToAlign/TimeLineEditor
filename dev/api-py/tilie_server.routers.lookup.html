tilie_server.routers.lookup#

MusicBrainz through a Reconciliation Service API 0.2 endpoint.

The editor looks values up in MusicBrainz through this server, which keeps MusicBrainz’s rules of use for all its requests (see tilie_server.musicbrainz). The endpoint speaks the W3C Entity Reconciliation Community Group’s Reconciliation Service API, version 0.2, so the editor reaches it with the same generic client as any conforming service:

  • GET /api/reconcile/musicbrainz, the service manifest;

  • queries=<JSON> (GET or a POST form), reconciliation queries;

  • extend=<JSON> (POST form, or GET), data extension with the properties name and sameAs;

  • GET …/suggest/entity, entity suggestions;

  • GET …/properties, the properties a type can be extended with.

An identifier is <type>/<mbid>, so the identifier space http://musicbrainz.org/ followed by it is the entity’s IRI (http://musicbrainz.org/work/<mbid>). sameAs lists the IRIs that timetoshare’s catalogue recognises in an entity’s URL relationships; the catalogue is imported when a request needs it, so a server whose timetoshare lacks it answers every other request.

Form bodies are read with the standard library, and refusals are answered 422 with {"detail": <message>}; a failure of MusicBrainz itself 502.
