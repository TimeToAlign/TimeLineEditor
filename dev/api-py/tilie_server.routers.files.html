tilie_server.routers.files#

The user’s files below the server’s root folder: list, read and write.

GET /api/folders lists one folder, GET /api/files reads a file and PUT /api/files writes one (decisions/0033-server-file-access.md). A path is the query parameter path, POSIX and relative to the root, "" the root itself. Every path is resolved, each symbolic link followed, and refused when it does not lie in the root or names a hidden place below it (a segment starting with .). Only the files TimeLineEditor opens are read and listed, workspace, manifest and table files, and only the one it saves through the server is written, the workspace file.

tilie_server.routers.files.READ_KINDS = ('.tle.json', '.yaml', '.yml', '.json', '.parquet')#

The ends of the names TimeLineEditor lists and reads, matched in any case.

tilie_server.routers.files.WRITTEN_KINDS = ('.tle.json',)#

The ends of the names TimeLineEditor writes, matched in any case: workspace files.

tilie_server.routers.files.resolve(path)[source]#

The absolute path path names, every link followed but one in a loop.

A link in a loop is left in the path unresolved, with the segments after it, on every Python version: Path.resolve does so from Python 3.13 on but raises RuntimeError up to 3.12, so this calls the function it builds on, os.path.realpath, which leaves the loop in place everywhere. status_of then finds the link, or nothing behind it.

Parameters:

path (Path)

Path

tilie_server.routers.files.write(root, path, body)[source]#

Write body into the workspace file path names, replacing it whole.

The bytes go to a new file beside it, which then takes the file’s place (os.replace), so the file is never seen half written. A file replaced keeps its mode; a new one is created as open creates it, under the process’s umask.

Raises:

Refused – The path is refused as inside refuses, ends in /, names (or leads through a link to) a file that is no workspace file, lies in no existing folder, names a folder, or names a file or lies in a folder the user may not write.

Parameters:
