How finely a position on a timeline is picked and a float shown: a fraction axis picks multiples of 1 / denominator at the finest, a float axis decimals of at most decimals places, and a float is shown with decimals places. An int axis picks integers at the finest and has no setting.

WorkspaceSettings#

Defined in: workspace/view.ts:89

How the editor is used on this workspace: the canvas’s snapping grid, the placement of new blocks, the granularity of positions on timelines, how each block’s manifest is written to a file and which of its MatchClaims are shown. The MatchClaim table itself is never held. No command changes a setting, so the journal neither records nor undoes them (Store.configure).

readSettings()#

readSettings(value, path, problems, lenient?): WorkspaceSettings | undefined

Defined in: workspace/view.ts:453

Read workspace settings, every member required and none unknown; the problems go to problems and the result is undefined when there are any. With lenient, as a workspace file is read, a granularity that does not read as one (missing, or of another shape) is read as DEFAULT_GRANULARITY, a manifests or matchClaimFilters that is missing or no object as none and each of its entries that does not read is left out, without a problem: settings lie outside the journal, so nothing a replay needs is lost. Every other member is read strictly either way.
