MatchClaimColumns#

Defined in: matches/columns.ts:49

The MatchClaim table’s columns: rows rows, a claim ID per row, the sides A and B, and per row whether it has a start anchor and an end anchor (1 or 0). A NOMATCH or conceptual MatchClaim has neither; a row with an end anchor has a start anchor. A value column’s cells of a row without that anchor are not read.
