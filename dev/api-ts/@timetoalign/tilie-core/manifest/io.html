normalizeManifest()#

normalizeManifest(value): Manifest | LoadError

Defined in: manifest/io.ts:424

A manifest from a value with bare IDs, the one way such a value becomes a Manifest: its @context cut to the prefixes it declares itself and uses (withStatementContext), as every value a command gives or leaves is, the schema validates it (schemaChecked), then it is put in its complete form (every default written out, whether it was complete or minimal or anything between), in canonical order, its segments unlocked, its invariants checked, its graphical declarations’ numbers made doubles, and its missing styles completed. schemaChecked()#

schemaChecked(value): Problem | { }

Defined in: manifest/io.ts:140

A manifest written with bare IDs, as TiLiE holds every manifest, as the schema accepts it, or the schema’s first problem: the value as a file writes it (manifestFileValue) is checked, and the problem’s path leads into the value itself (idFormPath). The value is returned as TiLiE holds it, its @context cut to the prefixes it declares itself (withStatementContext). The one schema check of a manifest TiLiE holds.

The file form differs from the value only in its IDs, written #id, and its full context, so the value itself is returned with the context core holds of the checked file form (withContextOf), its IDs never read back from the file form. A value without @context declares no prefix, so it is held without one as it is.
