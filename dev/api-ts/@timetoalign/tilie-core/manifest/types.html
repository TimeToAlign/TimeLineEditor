AxisValue#

AxisValue = ReadonlyView<Lossless<SchemaNumber>>

Defined in: manifest/types.ts:47

A value on its timeline’s own axis (a length, an offset, a region’s start and end, a flow-control element’s coordinate): a JSON integer, a JSON number or a [numerator, denominator] pair, as the axis’s number type selects, each number as the reader returns it (an integral float in a pair is a JsonFloat): the read-only view of the schema’s Number read losslessly.

Elision#

Elision = ReadonlyView<CompleteElision>

Defined in: manifest/types.ts:147

An elision of a manifest, {id, timeline, start, end, name?, width?, display}: a stretch of the timeline it names, its start and end (and a width’s span) bare values on that timeline’s own axis as the reader returns them, its display always stated, in the schema package’s canonical order (ELISION_DISPLAY). It is carried through unchanged; the drawing leaves its stretch out (docs/drawing.md sections 2 and 8.9).

FlowControlElement#

FlowControlElement = ReadonlyView<CompleteFlowControlElement>

Defined in: manifest/types.ts:72

One element of a timeline’s flow control, discriminated by its role: a jump (holding its destinations as targets), a jump_target, a break (which may state when it ends the flow, ends), a section_break or a barline. Each may carry provenance, whose entries are about the element itself.

ManifestGraphical#

ManifestGraphical = Omit<Graphical, "timestamps" | "matchstamps" | "elisions"> & object

Defined in: manifest/types.ts:157

A manifest’s styling, its display and band orders, its named timestamps, its named MatchStamps and its elisions, owned by the manifest, never by a canvas. The numbers of its declarations are plain doubles: the schema boundary (normalizeManifest) reads a declaration’s integral float as the double it equals; a named timestamp’s coordinate and an elision’s values are own-axis values and stay as read.

A named MatchStamp, {id, name, alignment_anchors, match_claims}: its alignment anchors, each joining two match timestamps, and the IDs of the MatchClaims behind it when it was named or last updated.

NamedTimestamp#

NamedTimestamp = ReadonlyView<CompleteTimestamp>

Defined in: manifest/types.ts:117

A named timestamp of a manifest, {id, timeline, coordinate, name?, display, matchstamp}: its coordinate a bare value on the own axis of the timeline it names, as the reader returns it (an integral float on a float axis a JsonFloat, an integer beyond 2^53 a bigint), like every other own-axis value; its display always stated, in the schema package’s canonical order (TIMESTAMP_DISPLAY). A match timestamp (matchstamp: true) is one of the named MatchStamps’ and may have no name.
