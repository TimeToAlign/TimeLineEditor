skeletonOf()#

skeletonOf(manifest): Skeleton

Defined in: manifest/statements.ts:153

The statements of manifest alone, at the paths they have in it, with the full context a file writes (fullContext: the format’s terms and every prefix the statements use). The schema package’s statement functions run on it, never on a manifest core holds: they return deep copies, and a copy made structurally would lose what core reads losslessly. Memoised by identity.

withoutReferencesTo()#

withoutReferencesTo(manifest, removed): Manifest

Defined in: manifest/statements.ts:425

manifest without the references to the elements whose bare IDs removed holds, in the statements and provenance of every element: a value that is a node naming one ({id: "#X"}) is dropped, as is a provenance entry whose value names one; #X is dropped from every basis and stated_by, a service #X is dropped; a list, an ordered list, a node, a container or a provenance left empty loses its key. A reference into another manifest (other.yaml#X) is kept. manifest itself where nothing names a removed element.

withStatementContext()#

withStatementContext<T>(manifest): T

Defined in: manifest/statements.ts:239

manifest with the @context core holds: of its own @context, only the prefixes it declares itself (no format term, no catalogue prefix with the same namespace) that its statements and provenance use, in their order; no @context where none is left. manifest itself where that is its @context already, and where its @context is no object, which the schema check then refuses.
