ELISION_LABELS#

const ELISION_LABELS: readonly ["name", "id", "coordinate"]

Defined in: manifest/elisions.ts:23

The words of an elision’s display that name its labels, in the order its stack holds them (drawing.md sections 2 and 6.4, Markers): its name, its ID, its elided coordinates. Each is a label element addressed {id: E, part: [word]}; a derived elision, which has no ID, has no id label, its others addressed {id: T, part: ["elision", word]}.

defaultElisionTimelines()#

defaultElisionTimelines(manifest): ReadonlySet<string>

Defined in: manifest/elisions.ts:125

The timelines on which an ancestor card may derive elisions (drawing.md section 8.9), memoised by the manifest’s identity: for every ancestor card of a root R aligned to a member M with the ancestors A1 = R, …, Ak, R and every child of A1 to A(k − 1) (the depths 1 to k). A card derives them only where its elision-mode is proportional, or auto without a stored card elision on R’s tree (elisionsUnder), and its proportion below 1; which of these timelines take a gap depends on its elision-depths, the view the drawing is made for and the rules that display children. The mode and the rest are the cascade’s and the drawing’s, which core does not read, so this is every timeline any mode lets the card derive one on. An ungrouped root’s card derives none.

elisionsOn()#

elisionsOn(manifest, timeline): readonly object[]

Defined in: manifest/elisions.ts:37

The stored elisions lying on the timeline timeline, card and group elisions alike, in the order graphical.elisions lists them, which is canonical (by timeline, then start, then ID) in a manifest in canonical order; none when it has none. Memoised by the manifest’s identity.

elisionsUnder()#

elisionsUnder(manifest, root): readonly object[]

Defined in: manifest/elisions.ts:83

The stored card elisions lying on the timeline root or on a descendant of it, in the order of graphical.elisions: every stored elision of that tree whose timeline lies in no group (drawing.md section 8.9), which decides a card’s auto mode and which Remove all takes from a root’s cards in one remove. A group elision of the tree is none of them. None for an ID naming no timeline.

groupElisions()#

groupElisions(manifest, group): readonly object[]

Defined in: manifest/elisions.ts:104

The group elisions of the group group: every stored elision whose timeline lies in it, a member or a member’s descendant (groupsHolding, drawing.md section 8.9), in the order of graphical.elisions. An elision on a timeline lying in several groups is a group elision of each. None for an ID naming no group.
