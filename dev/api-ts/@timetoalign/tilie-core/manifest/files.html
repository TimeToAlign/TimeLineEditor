virtualDrawing()#

virtualDrawing(manifest, id): MemberDrawing | undefined

Defined in: manifest/files.ts:177

The member drawing of the virtual timeline id of manifest (section 8.10), which is drawn as a root holding nothing: a timeline of its ID, name, unit, number type and length, locked (its end is fixed by its map), without children, conversion maps, regions or flow control, and without ancestors; one object per manifest and ID, so every reader keyed by a member drawing reads the same. undefined for an ID no virtual timeline carries.
