bandOrderOf()#

bandOrderOf(manifest, timelineId): readonly string[]

Defined in: manifest/order.ts:107

The band order the timeline timelineId is drawn with, line and all five facets: its own entry in graphical.order completed against the order it inherits (inheritedBandOrder), else that order. A virtual timeline, which lies in no tree, completes its own entry against the default band order, as a root does (drawing.md section 8.10). Any other ID gets the default band order.

bandOrderProblem()#

bandOrderProblem(manifest, timelineId, value): string | null

Defined in: manifest/order.ts:136

The first problem of value as the band order of the timeline timelineId, its entry in graphical.order, in the terms and the order of TimeToShare’s README and validators, IDs and entries in single quotes; null for a band order. The schema’s problems about the value’s shape and its repeats come first, then the identity rules’:

  1. a value that is not an array of strings: the band order of '<id>' is not an array of strings;

  2. an entry repeating an earlier one: '<entry>' is repeated in the band order of '<id>';

  3. an ID no timeline and no virtual timeline carries (a group’s ID is a display order’s key, never asked here): '<id>' names no group, timeline or virtual timeline of this manifest;

  4. the first entry that is neither line nor a facet: '<entry>' is not 'line' or a facet, in the band order of '<id>';

  5. a value without line: 'line' is missing from the band order of '<id>'. A facet the value leaves out is no problem: it takes its place from the order the timeline follows without an entry (bandOrderOf).

inheritedBandOrder()#

inheritedBandOrder(manifest, timelineId): readonly string[]

Defined in: manifest/order.ts:81

The band order the timeline timelineId follows without an entry of its own in graphical.order: a root the default band order, every other timeline its parent’s band order (bandOrderOf), completed. A member that is a child timeline follows its parent so too. An ID no timeline carries gets the default band order, as a root would.
