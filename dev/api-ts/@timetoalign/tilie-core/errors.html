Problem#

Defined in: errors.ts:84

One problem: a code from ErrorCode, a description, and the path of the offending value.

For a load, the path points into the text read: into the manifest, or into the workspace file (["blocks", <id>, "manifest", ...]). For a command, it starts with the address key (addressKey) of the target at fault, followed by the property at fault ([<address key>, "length"]) or, for a value add puts in, by its kind and the location in the value ([<address key of into>, "timeline", "id"]). A problem of the manifest the command would leave lies there instead: at the block’s ID, "manifest" and the location in that manifest ([<block id>, "manifest", "timelines", 0, ...]). Only a malformed command, which has no target, names the malformed member of the command itself.

Defined in: errors.ts:168

The end of a closed switch over the kinds of a union: once every kind has its case, value has the type never, so a kind added to the union later fails to compile until the switch takes it. Reached at run time only through a value its type does not admit; it then throws, naming the value’s kind where it has one.
