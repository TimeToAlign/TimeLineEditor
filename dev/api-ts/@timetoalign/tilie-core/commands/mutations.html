commands/mutations#

Interfaces#

ChangeSet#

Defined in: commands/mutations.ts:52

What a command changed. blocks are the blocks it added, removed or changed; manifests those of them whose manifest changed, which settle completes, orders and checks; paths the [<target's address key>, property] of every value a set stored that differs from the one stored before, and for the other commands the path each acted on; targets the address of every target a change was made at. written holds, by path, each value a set wrote that reaches no further than its path; reaching the blocks a change reached past its path in (a whole manifest replaced, a timeline moved, placed or grouped), which only the whole block compares. ids gives the ID of every element the command creates, in order.

replaceTimeline()#

replaceTimeline(manifest, at, timeline): Manifest

Defined in: commands/mutations.ts:202

manifest with the timeline at locates replaced by timeline. Where the new timeline’s length is known and another than the old one’s, the named timestamps lying at the old end move to the new one, and the stored elisions ending there end at the new one: what lies at a timeline’s end stays at its end whatever changes the length (lengthProblem refuses a length at or before such an elision’s start).
