coordinateText()#

coordinateText(value, numberType, unit): string

Defined in: layout/src/numbers.ts:88

A coordinate label (section 5.2): the pretty text of a value on an axis of numberType and unit, rounded as a label is, to three places. An exact value is an int on an int axis where it is integral, else a fraction; a float value, a sum involving a float, is a float whatever the axis. Without a unit, the text has no pretty unit.
