flows()#

flows(manifest, timeline, options?): Promise<Flows>

Defined in: index.ts:197

The flows of the timeline timeline (its bare ID) of a manifest, as timetoalign plays its flow control: one request for the manifest’s text, sent unchanged. Resolves to the timeline’s atomic sections and, for the convention asked for or for all three, the runs played, the sections they cover and the findings, each with its cause where timetoalign names one, the elements read as options.reading says. A timeline without flow control is one section and one run. Rejects with a ServerError, whose refusal says what the server refused (a timeline the manifest lacks at ["timeline"], a manifest timetoalign refuses at the place in it).
