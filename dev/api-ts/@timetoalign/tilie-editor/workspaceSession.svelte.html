loadNamedTables()#

loadNamedTables(): Promise<void>

Defined in: editor/src/workspaceSession.svelte.ts:659

Load the MatchClaim table every block’s manifest names where it is not loaded (what turning Show matches on asks), block after block in the canvas’s one order of blocks (the arranger’s blocksInOrder): from beside the manifest’s file (or where an example came from), silently, else as the user chooses it (MatchClaimTables.loadNamed); what each load says is posted (report). Where no block holds a table then, the message bar says so as information (NO_MATCHES). While no server can read a table nothing is asked: where no block holds a table or a block’s manifest names one the block does not hold, the message bar says as information that matches need a running server and how to start one (HOW_TO_START_A_SERVER), in place of every question. A server that answered reads tables whether or not it offers the user’s files; where it offers none, a table is looked for beside an example alone, else asked for (MatchClaimTables.loadNamed). While the server given has not answered its health check yet (MatchClaimTables.waiting) nothing is said: it may be slow rather than missing, and the editor calls this again once it answers. A call while one is under way is ignored.

Returns#

Promise<void>

save()#

save(as): Promise<void>

Defined in: editor/src/workspaceSession.svelte.ts:395

Save the open workspace: back into its file, or, with as, without a file to write back to (a new workspace, one without a handle), or after a rename since it was last opened or saved (until the rename is undone), to a file the user chooses now, offered under the workspace’s file name: the one its name gives for a new or renamed workspace, else its file’s. Through the server (FileHost) the file is a path chosen in the file dialog, and a save into another folder first rewrites every block’s manifest location relative to that folder; otherwise it is the browser’s (saveFile), and where that downloads, the page says so once. A save requested while one is under way is ignored.
