readProfiles()#

readProfiles(value, catalogue): string | Profiles

Defined in: editor/src/profiles/profiles.ts:261

The profiles and services value holds, or the first problem, its path written profiles/0/verbs/1: …. Read in this order: the root’s members; the services (an ID twice is refused); each profile’s members, ID, label, “is a” (catalogue systems, patterns whose IRIs are absolute or under the catalogue’s prefixes), verbs (catalogue verbs, none twice) and lookup systems (catalogue systems and the file’s services, none twice); and last an ID given to two profiles.
