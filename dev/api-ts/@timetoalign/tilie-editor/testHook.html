hookBands()#

hookBands(drawing, box): HookBand[]

Defined in: editor/src/testHook.ts:114

The bands of drawing, in its box order, shown in the client rectangle box (its <svg>’s): each band’s line ordinate and rectangle mapped from the drawing’s units into client pixels by the scale of the rectangle to the drawing, the inverse of the <svg>’s screen transform the canvas reads a pointer through while the drawing is shown unrotated. Nothing is clipped: a drawing off screen gives what this computes.
