LookupError#

Defined in: editor/src/lookup/kinds.ts:86

A request a service did not answer as asked: unreachable when no answer came, status when the answer’s HTTP status is not 2xx, malformed when its body is not of the service’s form. The message completes a sentence naming the system (“Wikidata could not be searched: ”).
