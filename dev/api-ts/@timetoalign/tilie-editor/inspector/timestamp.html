timestampText()#

timestampText(format, pin): Result<Text>

Defined in: editor/src/inspector/timestamp.ts:249

pin’s timestamp as text in format: core’s timestampJson written by the inspector’s codec. The text is a readout, not a manifest, so the manifest’s null rule does not apply to it: in TOML, which has no null, every member whose value is null (a map without a value at the position, a measure’s missing number or length) is left out; JSON and YAML keep it.
