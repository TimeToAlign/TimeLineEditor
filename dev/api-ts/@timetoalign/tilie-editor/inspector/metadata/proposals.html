proposed()#

proposed(frame, found, answers, prefixes, day): object

Defined in: editor/src/inspector/metadata/proposals.ts:203

The skeleton with the best candidate of each name written as TiLiE’s candidate (TimeToShare’s withCandidate): the candidate of the first system in RECONCILING that found one, {id} under the name’s property on the name’s subject, reconciled by the candidate’s service on day, its match exact where the service says it matches and none where it says nothing, and the note naming the name. A pair the subject already states, or has any entry of (a candidate, believed false by someone or not), is passed over. With the number proposed, and how many went to each element (placed, those given one, in the order of their names).

statedForName()#

statedForName(frame, row, actor, day): Skeleton | null

Defined in: editor/src/inspector/metadata/proposals.ts:282

The skeleton with a candidate for a name stated by actor on day: where the candidate’s value is a thing (a node with id) and its subject states exactly one name under a property of the same IRI (a value node with a label and no id), that name is taken out and the thing stated in its place, the name’s node with the thing’s id, so its label and other keys stay; the candidate’s entry becomes the stated pair’s, with the actor’s belief true. null for any other candidate, and where several names could be the one: the candidate is then stated as it is. The entry’s note is words and is never read.
