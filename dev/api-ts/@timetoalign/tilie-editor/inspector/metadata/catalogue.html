systemChoices()#

systemChoices(catalogue, verb, types?): readonly SystemChoice[]

Defined in: editor/src/inspector/metadata/catalogue.ts:246

The vocabularies a reading can be stated in: those with a pattern of it, and those whose lookup searches its kind of value (the viewer’s services, after the catalogue’s systems, search every kind) where the fallback states it with a thing slot; first the systems the subject’s types prefer, in their order (preferredSystems), then the rest in catalogue order; then “An element of this manifest” where the fallback has that slot.
