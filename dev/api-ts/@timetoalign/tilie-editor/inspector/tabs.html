elisionSelected()#

elisionSelected(shown, view, addresses, openings): Shown

Defined in: editor/src/inspector/tabs.ts:175

What is shown once the selection changed to addresses: when they are exactly one elision, stored or automatic (namesElision), the Elisions tab, as though it were chosen (chosen: the pin cleared), remembering no tab to go back to, so the tab stays once the selection leaves the elision; any other selection, several things with an elision among them included, changes nothing (shown itself). Told of a change of the selection only, never while the same elision stays selected, so a tab chosen meanwhile stays.

toggled()#

toggled(picked, openings, shown): Picked

Defined in: editor/src/inspector/tabs.ts:71

The pick once the inspector is shown (shown true) or hidden. Hiding it records the count of openings; showing it again shows the level tab when an editor was opened while it was hidden (the count differs, as it does for a store replaced meanwhile), else the tab chosen. While the inspector is shown nothing but a choice changes the pick, so entering or leaving an editor never changes the tab shown.
