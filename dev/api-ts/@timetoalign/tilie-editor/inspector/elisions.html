blocksOf()#

blocksOf(root, group, form): ElisionBlocks

Defined in: editor/src/inspector/elisions.ts:1360

The blocks of root, group and form as the tab shows them. The selected elision of form is held by the group’s block where the group lists it, else by the root’s (a card elision of the root, or a default one); the block holding it and the form’s own block are open without a click, every other block is collapsed. An action taken in a block opens it under its own key (keeps), so that it stays open once the selection leaves it.
