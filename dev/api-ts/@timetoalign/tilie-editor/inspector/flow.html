beliefCommand(__namedParameters, user, belief, day): SetCommand

Defined in: editor/src/inspector/flow.ts:340

The set recording user’s belief in the element on day (YYYY-MM-DD): the element’s belief, the user named as in every statement (statedBy). Core puts it into the element’s provenance, in place of the user’s earlier one, and changes nothing else of it. A belief false rejects the element; another one believes it again.
