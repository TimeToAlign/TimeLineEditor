nameOf()#

nameOf(view, subjects, editing): NameField | null

Defined in: editor/src/inspector/properties.ts:682

The name the Properties tab shows first: with nothing selected, the workspace’s at the top level, and in an editor the edited element’s (the address its opening selects, editedSelection); else the one inspected thing’s. Each wherever the schema gives it a name (the block’s manifest, a group, a measure map, a timeline or its card, a conversion map, a region, a flow-control element, a named timestamp, a MatchStamp, a stored elision, a FlowMap made by hand, a virtual timeline or its card; a part names its element’s, a default elision none); a match timestamp’s and an elision’s name may be emptied, a named timestamp’s and a MatchStamp’s not; null for a band, an alignment anchor, a computed FlowMap (which refuses every change), a chunk or several things.

propertyCommand(view, geometry, property, input): Edit

Defined in: editor/src/inspector/properties.ts:539
