drawingOf()#

drawingOf(block, graphical, metrics, overrides?, pane?): Drawing

Defined in: arranger/src/drawing.ts:80

The drawing of a block: its manifest drawn at its placement with the default layer, the workspace’s graphical and the manifest’s own (manifestLayer: its styles and rules), from lowest to highest, for the pane pane of the canvas showing it (its view, the placement’s view; layout’s default view without one) where the manifest draws an ancestor card, whose automatic proportion alone reads it (and only then is the pane read, so a reaction drawing any other manifest never follows it). Blocks are immutable, so the drawing is memoized per block and redrawn only when the workspace’s graphical, the metrics or the pane change. overrides replace members of the block’s placement (a resize measuring the content at another length or with no size request). Every drawing is also kept by its manifest and its placement’s values, the RECENT last of a manifest: a resize measures one block at many placements on every pointer move, and the block its preview stores draws one of them again.

raisedLayers()#

raisedLayers<E>(entries, drawing, root): object

Defined in: arranger/src/drawing.ts:180

The entries of a block in the layers it shows them in (stackingOf): below, every entry no raised card draws, in drawing order, then each displayed ancestor card of the root root (raisedRoot, or the root a raise is folding back, Unfolding.root) in record order with the entries it draws (its rectangle and its drawing, the record’s range). With no root, or a root without a displayed ancestor card, below is entries itself (the same array) and nothing is raised. The drawing is never changed: only the order and the layers the block shows it in.
