readingAt()#

readingAt(nodes, point, options): Reading | null

Defined in: arranger/src/coordinates.ts:1254

The reading of the canvas point point over nodes at zoom, with ratio device pixels per CSS pixel: of every node whose drawing holds a line point hovers (lineAt, HIT_TOLERANCE device pixels around, where it is not covered: stackingOf, the root raised by the node’s editor, raisedRoot), the nearest, a later node on a tie; null where no line is hovered. A node in which the point lies inside a gap of an elision (gapAt) reads nothing: the stretch it elides is not drawn there, so nothing is placed, not even the end of a run beside it; every full run of an elided line is a line of its own (axesOf), read alike, and a position read at a seam lies on the run holding it (seamHit). An ancestor line is read as its ancestor’s (crossSectionSpec). The position is core’s snapOnRow on the hovered row (rowOf) of the line’s cross-section (crossSectionSpec), p the pointer’s coordinate on the line’s axis and h half a device pixel there: the line’s drawn length (up to its reach where its length is not known) over its width, over zoom × the block’s scale × ratio, halved. Above a timeline editor (groupScoped of the node’s editor) the cross-section also holds every member of each group whose frame draws the hovered line’s timeline, read by the group as a groupstamp’s (withGroupMembers). knotsOf gives the expanded MeasureMaps of a manifest, or why they are not at hand; without it no server expands them. A point that is not finite reads nothing.
