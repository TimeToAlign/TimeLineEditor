focusOn()#

focusOn(target): Promise<void>

Defined in: arranger/src/editorFocus.svelte.ts:129

Centre the edited element target in the canvas, once the page has settled: the inspector may open with the editor, and the canvas, which lies left of it, is measured after it has. Its width is therefore the area left of the drawer, and no drawer width is taken off. A group whose frame has elided ancestor cards behind it is zoomed out until they fit on both sides of the frame’s centre (elidedReach); in the Full view the frame alone decides and the cards may run past the edges. A target that is not drawn (a hidden element) leaves the view where it is.

follow()#

follow(store, next): void

Defined in: arranger/src/editorFocus.svelte.ts:99

Follow the editing path next of store: an editor opening pushes the viewport and moves the view to the edited element; an editor closing pops the viewport its level was entered from and moves the view back there. A level entered while the view is still moving to the level below returns to where that move was heading, which is where the level below is shown. A store of its own starts with no viewports to go back to.

resized()#

resized(): void

Defined in: arranger/src/editorFocus.svelte.ts:174

The canvas has changed size (the inspector drawer opening or closing beside it, the window resized): with an editor open, its element is centred again to fill the new area, as on entering. A size the view was already focused at moves nothing, so the measurement that follows an editor’s opening (and the drawer opening with it) does not move the view a second time. The viewport an editor returns to on Done stays the one it was entered from.

Returns#

void

settled()#

settled(): void

Defined in: arranger/src/editorFocus.svelte.ts:156

The pane has settled at a new size, PANE_SETTLE after the canvas last changed size, and every drawing is drawn again for it (an ancestor card’s automatic proportion reads the pane): the centring done when the canvas changed size measured the drawing of the size before. With an editor open and the view still where it was last centred (or heading there), the edited element is centred again on its new drawing; a view moved since, also by the user during that move, is left where it is.
