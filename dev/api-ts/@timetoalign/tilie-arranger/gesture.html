GestureSlot#

Defined in: arranger/src/gesture.ts:80

The gesture in progress on one canvas, which Escape on the canvas ends. A pointer drives one gesture at a time; the canvas holds one slot in its context, so two canvases on a page never end each other’s gestures.

GestureStrategy#

Defined in: arranger/src/gesture.ts:56

What a gesture does, from press to command. P is what a press holds, V the plain value the pointer stands for (a point, an order, a delta): the engine previews a value only when it differs, member by member, from the last one previewed.

CLICK_DISTANCE#

const CLICK_DISTANCE: 4 = 4

Defined in: arranger/src/gesture.ts:34

How far, in screen pixels, a pointer may move between press and release and still click (touch and trackpads wobble). Svelte Flow’s pane uses the same distance for a click and a marquee.
