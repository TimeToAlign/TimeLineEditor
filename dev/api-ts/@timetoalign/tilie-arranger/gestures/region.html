regionDrag()#

regionDrag(context, subject, edge, dx, tolerance, reach): Rational | null

Defined in: arranger/src/gestures/region.ts:201

The value the edge of subject takes when its handle is dragged dx block units: the value of the region’s timeline the card’s axis reads at the end’s abscissa moved by dx (beyond the axis or inside a gap, the end moved by dx / k, k the block units per unit of the timeline on the run the end lies on), snapped to a value of targetsOf within tolerance block units, else to the simplest value of its number type within reach block units (core’s snapOnRow), held where the end may lie: never past the region’s other end, nor before its timeline’s start or after its known end. null where the axis has no scale there.
