resizeGesture()#

resizeGesture(host, handle): GestureStrategy<ResizePress, Delta>

Defined in: arranger/src/gestures/resize.ts:60

The resize by handle: the pointer’s travel in canvas units (its screen travel less the viewport’s pan since the press, over the zoom) is the resize’s delta. A block becomes new placement values (resize), a frame or a card new places (itemResizeValues); the release stores them in one set, nothing when every value is stored already. While the pointer lies in the pane’s edge band the canvas pans every frame, and the preview follows the canvas point under the pointer, as Svelte Flow does for a node drag.
