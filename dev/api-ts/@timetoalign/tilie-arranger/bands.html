bandDrop()#

bandDrop(drawing, band, y, order): readonly string[] | null

Defined in: arranger/src/bands.ts:89

Where a drag of band released at the drawing ordinate y lands: the new own band order of its timeline, or null when nothing changes. order is the timeline’s effective band order (core’s bandOrderOf). Of the visible entries without the dragged band, let k be how many lie above y; the band moves in order to just after the k-th of them, or just before the first when k is 0. When the band already lies between those two neighbours in order, relative to them alone, the result is null: a release in place never writes. A drop across the line follows the same rule, line being a visible entry like any band.

bandMoveCommand()#

bandMoveCommand(view, block, timeline, order): SetCommand

Defined in: arranger/src/bands.ts:131

The one set that gives timeline of block block the band order order: one change {target: {block, id: timeline}, values: {order: X}}, X being order, or null when order equals the timeline’s inherited band order (core’s inheritedBandOrder over the block’s manifest), so the timeline inherits again. A move is one command, one journal entry, one undo step.

bandStep()#

bandStep(drawing, band, direction, order): readonly string[] | null

Defined in: arranger/src/bands.ts:107

band moved past the next visible entry in direction, the timeline’s line included, so every step changes what is seen: the new own band order of its timeline, or null when no visible entry lies that way (the top or the bottom). order is the timeline’s effective band order.

bandStepCommand()#

bandStepCommand(view, address, direction, editing, metrics, pane?): SetCommand | null

Defined in: arranger/src/bands.ts:158

The set that steps the selected band address past the next band or line drawn in direction (bandStep, bandMoveCommand): null unless address names a band the view offers under editing (offersBand) that its block’s drawing records, and when nothing lies that way. Whether the canvas moves bands at all is the caller’s question (rulesOf).
