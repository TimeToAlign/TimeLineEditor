# TimeLineEditor

TiLiE, the TimeLineEditor, is a local browser editor for musical timelines:
it edits workspaces whose blocks each hold a TimeToShare manifest. This site
holds its documentation: an overview of the editor, the architecture of the
app and the server, how to develop them, the API of the Python server
`tilie_server` and of the app's TypeScript packages, the design decisions,
the changelog and the contributing guide.
